## 🚀 How to Run Locally

### Option 1: Instant Browser View (Zero Setup)
Simply double-click `index.html` in your Windows file explorer. It will open in Google Chrome, Microsoft Edge, or any modern web browser.

### Option 2: Using Python's Built-in Server
Open PowerShell in this project folder and run:

```powershell
python -m http.server 3000
```

Then open your browser and visit: `http://localhost:3000`

## 🌐 How to Deploy to Vercel (Free & Instant)

This project is pre-configured with `vercel.json` for seamless deployment.

### Method A: Via GitHub (Recommended)
1. Initialize a git repository and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Fathima Fida Data Analytics Portfolio"
   ```
2. Create a new repository on your GitHub account ([https://github.com/fida-saleem](https://github.com/fida-saleem)) named `data-analytics-portfolio`.
3. Push your repository:
   ```bash
   git remote add origin https://github.com/fida-saleem/data-analytics-portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. Go to [https://vercel.com](https://vercel.com), sign in with your GitHub account, click **"Add New Project"**, select your repository, and click **"Deploy"**.
5. Your portfolio will be live worldwide with a free `.vercel.app` URL and automatic HTTPS!

### Method B: Vercel CLI / Drag & Drop
You can also drag and drop the folder directly onto the Vercel dashboard or run `npx vercel` if Node.js is installed.
